# Phase 9 — Optional Extras (pick any, one per task)

Each extra is independent. Do them only after Phase 8. Each must keep all previous acceptance checklists passing.

---

## 9.1 Shizuku mode (power features without root)

**What it adds:** faster/more reliable input in apps with poor accessibility, `uiautomator dump` as a second tree source, auto re-enabling the accessibility service after OEM kills it.

- Dependencies (ask first): `dev.rikka.shizuku:api` and `dev.rikka.shizuku:provider` (Apache 2.0). Add the `ShizukuProvider` to the manifest per Shizuku docs.
- Module `:feature:shizuku` with `ShizukuBridge`: `isAvailable()`, `requestPermission()`, `exec(cmd)` via a **UserService** (AIDL) — the recommended way; the older `newProcess` API is deprecated.
- Commands allowed (fixed whitelist, never from the LLM):
  - `input tap x y`, `input swipe x1 y1 x2 y2 ms`, `input text <escaped>`, `input keyevent <code>`
  - `uiautomator dump /data/local/tmp/omni.xml` + read file → parse into `Observation` (fallback source)
  - `settings put secure enabled_accessibility_services <existing>:<ours>` + `settings put secure accessibility_enabled 1` (auto re-enable)
  - `appops`/`pm grant` for our own app only (e.g. grant `WRITE_SECURE_SETTINGS` to ourselves once so re-enable works without Shizuku later)
- Settings toggle "Use Shizuku when available"; Capability Report shows status.
- Setup doc: install Shizuku, start via Wireless debugging (Android 11+), grant OmniControl. Note: Shizuku must be restarted after each phone reboot (non-root).

## 9.2 Quick Settings tile + home-screen widget

- `TileService` "OmniControl": tap → start session (tile clicks count as user interaction; use `startActivityAndCollapse` with a `PendingIntent` to a trampoline if the mic FGS needs it — API 34+ requires the PendingIntent overload).
- Glance widget (Jetpack Glance) with a mic button and last command.

## 9.3 Wake word (opt-in)

- sherpa-onnx KWS with a custom phrase ("hey omni"). Runs only while the bubble is visible and the user enabled it. Requires the microphone FGS to be active → the persistent notification and green mic indicator are shown the whole time (honest, visible). Battery cost documented.

## 9.4 Multilingual voice

- Add sherpa-onnx models for Hindi/Telugu or a multilingual model (Whisper small via offline recognizer for the 2nd pass). Language picker in settings. Prompt: tell the LLM the user's language for `say` texts; Android TTS voice per language.

## 9.5 Notification reader & replies

- Accessibility `TYPE_NOTIFICATION_STATE_CHANGED` events (or a `NotificationListenerService` — needs extra permission, ask first) to answer "read my latest WhatsApp message".
- Replies always go through SafetyGuard CONFIRM.

## 9.6 "Explain this screen" / read aloud

- Command "what's on my screen?" → read_screen with a description prompt; "read this aloud" → reading order text via TTS, with "next"/"stop".

## 9.7 Scheduled routines

- WorkManager schedules a reminder notification at a time ("Run 'morning news' now?"). Tapping it runs the routine (needs phone unlocked; never runs silently on lock screen).

## 9.8 Backup & restore

- Export routines, aliases, graph and settings as one encrypted JSON (password-based, `javax.crypto` AES-GCM + PBKDF2) via SAF; import on a new phone.

## 9.9 Smarter on-device model updates

- Model Manager "Try new model": download/import a GGUF, run the Phase 5 eval set on device, show score vs current model, switch with one tap.

## 9.10 Screen-aware suggestions

- When the panel is expanded and idle, show 3 suggestion chips based on the current screen ("Search", "Open first result", "Go to channel") — generated by FastRouter heuristics (no LLM) to keep it instant.
